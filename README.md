# Class 12 Holiday Homework Portal
A polished, single-homepage hub with subject pages for Physics, Chemistry, Maths,
English, and Physical Education. Built as a clean, fast, and visually rich site
with shared navigation, smooth section browsing, and an integrated Study Beats
player for focus sessions.

Live site: https://class-12-hhw.pages.dev/

---

## Highlights
- One-page hub with Quick Access and Homework Universe navigation
- Shared navigation injected across all subject pages via shared-nav.js
- Study Beats music sidebar with floating action button
- Consistent design system, smooth scroll, and animated accents
- Dedicated subject pages for homework, formulas, and projects

## How to Use Locally
1. Open index.html in a browser.
2. Use the subject cards to jump into any page.
3. The shared navigation loads automatically on sub-pages.

---

## Customization Notes
- Update shared navigation links and music settings in shared-nav.js.
- Edit index.html to change homepage sections or subject data.
- Edit subject HTML files to update content, images, or styling.
